# Illustration Credits

The bundled engravings are by John Tenniel for Lewis Carroll's *Alice's Adventures in Wonderland* (1865). They are public domain. Source: Project Gutenberg ebook 114, *The Tenniel Illustrations for Carroll's Alice in Wonderland*.

- `alice-frontispiece.gif`: <https://www.gutenberg.org/files/114/114-h/images/alice01a.gif>
- `white-rabbit.gif`: <https://www.gutenberg.org/files/114/114-h/images/alice02a.gif>

The application's book covers are original typographic designs, not reproductions of publishers' covers. Book summaries are original short descriptions, except the two existing summaries reused from this repository.

EB Garamond, DM Sans, and IBM Plex Mono are bundled from Fontsource under their respective SIL Open Font Licenses. Lucide icons are used under the ISC license. See the installed packages for license texts.
